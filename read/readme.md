ทุกอันที่นายแนะนำมาให้แก้ให้หมดเลย ยกเว้นเรื่อง crop เพราะเทสแล้วการครอปแบบนี้ให้ผลวิเคราะห์ที่ดีกว่า
จากนั้นอันนี้คือสิ่งที่อยากให้ทำเพิ่ม

1. หลังจากถ่ายรูปเสร็จอ่ะพอกดส่งจะยังไม่ให้เห็นผลลัพเลยแต่จะให้ user ทำแบบสอบถาม ตามไฟล์ question.txt เพื่อ mapping ข้อมูล user ตามไฟล์ ingredient.txt เพื่อนำไปสู่หน้าผลลัพท์ใบหน้าของ user
2. จากนั้นจะมีหน้าแนะนำ skincare ตามสภาพผิวที่เหมาะสมโดยจะขึ้นอันที่แนะนำที่สุดแต่ละหมวด Serum, Moisturizer, Cleanser, Toner, Cream, Sunscreen
3. โดยอันที่ไม่ match หรือ เหมาะสมหรือไม่ใช่อันที่เหมาะสมที่สุด จะสามารถดูเพิ่มเติมได้ที่หน้ารวมสกินเเคร์ user สามารถ search หาได้ โดยในส่วนที่ยังไม่ได้หาสกินเเคร์มาเลยคิดว่าค่อยเพิ่มทีหลัง อยากให้ทำระบบให้เรามาเพิ่มทีหลังได้ง่ายๆหน่อย
