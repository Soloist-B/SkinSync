ชุดแบบสอบถามสรีรวิทยาผิวเพื่อการคัดกรองทางการแพทย์ (Physiological Baseline & 
Clinical Triage Questionnaire) โดยอ้างอิงจากมาตรฐานการประเมินทางคลินิก (Clinical 
Assessment Standards) เช่น Baumann Skin Type System และ The Fitzpatrick Skin Typing 
Scale โดยจับคู่กับตรรกะการทํางาน (Backend Logic) ของระบบ 
1. หมวดความสมบูรณ์ของเกราะป้องกันผิว (Skin Barrier Integrity & TEWL) 
จุดประสงค์ทางคลินิก: ประเมินอัตราการสูญเสียนํ้าออกจากผิวหนัง (Transepidermal Water Loss) 
และความบกพร่องของไขมันเชื่อมเซลล์ผิว  
คําถาม: ในช่วง 1-2 สัปดาห์ที่ผ่านมา หากคุณล้างหน้าแล้วทิ้งไว้ประมาณ 1 ชั่วโมงโดยไม่ทาผลิตภัณฑ์
บํารุงใดๆ ผิวของคุณมีอาการเหล่านี้บ่อยเพียงใด (อาการ: แห้ง ลอก แสบ ตึง คัน)? 
● ตัวเลือก A: ไม่รู ้สึกแห้งตึง ผิวดูเรียบเนียนและชุ ่มชื้นปกติ 
○ ผลลัพธ์ในระบบ (Backend Logic): Barrier = Healthy (อนุญาตให้จ่ายสาร
ออกฤทธิ์ได้ตามปกติ) 
● ตัวเลือก B: รู ้สึกตึงผิวเล็กน้อยในบางบริเวณ หรือแห้งตึงเฉพาะตอนล้างหน้าด้วยนํ้าอุ่น 
○ ผลลัพธ์ในระบบ (Backend Logic): Barrier = Mildly Impaired (เฝ้าระวัง
ความเข้มข้นของการผลัดเซลล์ผิว) 
● ตัวเลือก C: รู ้สึกแห้งตึงมาก ผิวลอกเป็นขุย มีอาการคัน หรือแสบแดงร่วมด้วยเป็นประจํา 
○ ผลลัพธ์ในระบบ (Backend Logic): Barrier = Compromised 
○ คําสั่งที่ถูกทริกเกอร์: OVERRIDE = TRUE (หยุดจ่าย Active ingredients กลุ่มผลัด
เซลล์ผิวและ Retinoids ทุกชนิด ชั่วคราว และบังคับจ่ายสารกลุ่ม Lipid Matrix Repair 
ได้แก่ Ceramides + Cholesterol + Free Fatty Acids ในอัตราส่วน 3:1:1) 
2. หมวดระดับความไวผิวและภูมิคุ ้มกัน (Sensitivity & Immunological 
Reactivity) 
จุดประสงค์ทางคลินิก: ประเมินความไวของระบบภูมิคุ ้มกันผิวต่อสิ่งเร้าภายนอก และประวัติการเกิดผื่น
แพ้สัมผัส (Contact Dermatitis)  
คําถาม: เมื่อคุณทดลองใช้ผลิตภัณฑ์สกินแคร์ชนิดใหม่ หรือเผชิญกับสภาพอากาศที่เปลี่ยนแปลง ผิว
หน้าของคุณมีปฏิกิริยาอย่างไรบ่อยที่สุด (แสบแดงง่ายเมื่อใช้อะไรใหม่ๆ)? 
● ตัวเลือก A: ผิวทนทานสูง แทบจะไม่เคยมีอาการแสบ แดง หรือแพ้ผลิตภัณฑ์ใดๆ เลย 
○ ผลลัพธ์ในระบบ (Backend Logic): Sensitivity = Low 
● ตัวเลือก B: มีอาการคันยุบยิบ หรือแดงบ้างบางครั ้งในช่วงแรกที่ใช้ผลิตภัณฑ์ใหม่ แต่สักพักผิว
จะปรับตัวได้เอง 
○ ผลลัพธ์ในระบบ (Backend Logic): Sensitivity = Medium 
● ตัวเลือก C: ผิวแพ้ง่ายมาก มักเกิดผื่นแดง แสบร้อน คัน หรือสิวเห่อแทบทุกครั ้งเมื่อเปลี่ยนส
กินแคร์ 
○ ผลลัพธ์ในระบบ (Backend Logic): Sensitivity = High 
○ คําสั่งที่ถูกทริกเกอร์: BAN (Fragrance, Essential Oils, Alcohol Denat และสารกัน
เสียก่อการระคายเคือง) และ MODIFY (เปลี่ยน Vitamin C บริสุทธิ์ไปจ่ายอนุพันธ์ที่ 
pH เป็นกลางแทน เช่น THD Ascorbate หรือ SAP) 
3. หมวดระดับการผลิตนํามัน (Sebum Excretion Rate - SER) 
จุดประสงค์ทางคลินิก: ประเมินอัตราการผลิตนํ้ามันจากต่อมไขมัน (Sebaceous Gland Activity) เพื่อ
กําหนดเนื้อสัมผัสของผลิตภัณฑ์ที่เหมาะสม  
คําถาม: สังเกตความมันวาวของใบหน้าหลังล้างหน้า 2-3 ชั่วโมง (โดยไม่ได้ทาผลิตภัณฑ์ใดๆ) ผิวหน้า
ของคุณมีลักษณะอย่างไร? 
● ตัวเลือก A: ไม่มีความมันวาวเลย ผิวดูแมตต์ หรือรู ้สึกแห้งตลอดวัน 
○ ผลลัพธ์ในระบบ (Backend Logic): Sebum = Dry / Alipidic 
○ คําสั่งที่ถูกทริกเกอร์: VEHICLE TYPE = W/O Emulsion (Water-in-Oil), Cream, 
Balm และ PREFER = สารกลุ่ม Occlusives เคลือบผิวกันนํ้าระเหย 
● ตัวเลือก B: มีความมันวาวเฉพาะบริเวณ T-Zone (หน้าผาก จมูก คาง) แต่บริเวณแก้มปกติหรือ
ค่อนไปทางแห้ง 
○ ผลลัพธ์ในระบบ (Backend Logic): Sebum = Normal / Combination 
● ตัวเลือก C: มีความมันวาวเคลือบทั่วทั ้งใบหน้าอย่างชัดเจน หน้ามันเยิ้มได้ง่าย 
○ ผลลัพธ์ในระบบ (Backend Logic): Sebum = Oily / Acne-Prone 
○ คําสั่งที่ถูกทริกเกอร์: VEHICLE TYPE = Aqueous-based, Gel, Serum, Light fluid 
และ AVOID = สารกลุ่ม Highly Occlusive และกรดไขมัน Oleic Acid สูง 
4. หมวดระดับสีผิวตามธรรมชาติ (Fitzpatrick Skin Phototype) 
จุดประสงค์ทางคลินิก: ประเมินปฏิกิริยาของเมลาโนไซต์ต่อรังสี UV เพื่อประเมินความเสี่ยงในการเกิด
รอยดําลึกหลังการอักเสบ (Severe PIH)  
คําถาม: เมื่อผิวหน้าของคุณสัมผัสกับแสงแดดจัดเป็นครั ้งแรกโดยไม่ได้ทาครีมกันแดด การตอบสนอง
ของผิวเมื่อเจอแสงแดดเป็นอย่างไร (ไหม้แดงง่าย หรือ คลํ้าดําง่าย)? 
● ตัวเลือก A: ผิวมักจะไหม้ แดง แสบร้อนได้ง่ายมาก แต่แทบจะไม่เปลี่ยนเป็นสีคลํ้าเลย (ผิวขาว
มาก - Type I, II) 
○ ผลลัพธ์ในระบบ (Backend Logic): Fitzpatrick = Light 
● ตัวเลือก B: ผิวอาจมีอาการไหม้แดงบ้างในตอนแรก และหลังจากนั ้นจะเปลี่ยนเป็นสีคลํ้าขึ้น
แบบค่อยเป็นค่อยไป (ผิวสองสี - Type III) 
○ ผลลัพธ์ในระบบ (Backend Logic): Fitzpatrick = Medium 
● ตัวเลือก C: ผิวไม่เคยมีอาการไหม้แดงเลย แต่จะเปลี่ยนเป็นสีคลํ้าดําขึ้นอย่างรวดเร็วและ
ชัดเจน (ผิวขาวเหลือง เอเชีย ผิวคลํ้า - Type IV, V, VI) 
○ ผลลัพธ์ในระบบ (Backend Logic): Fitzpatrick = Type IV, V, VI 
○ คําสั่งที่ถูกทริกเกอร์: BAN = ห้ามแนะนําการลอกผิวด้วยกรดความเข้มข้นสูง, MODIFY 
= เปลี่ยนไปใช้กรดโมเลกุลใหญ่ที่ซึมช้าและปลอดภัยกว่า, และ CAP LIMIT = การจ่าย 
Retinol ต้องจํากัดความเข้มข้นเริ่มต้นที่ระดับตํ ่าสุดเสมอ
